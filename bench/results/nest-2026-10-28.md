### How much it moves between runs

This is the second of two runs a few minutes apart. Compared with the first: memory was within 3 MB
(251 / 333 / 492 MB), requests per second within 6% (121 / 258 / 235), start-up 1601 ms, and the
one-at-a-time times within about 20% (login 66 ms, the board query 8.2 ms). So only bigger differences
than that mean anything when comparing with the Rust backend.
